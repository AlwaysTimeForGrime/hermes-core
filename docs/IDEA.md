Build a Neo4j-backed memory layer that gives AI agents persistent, searchable, and relationship-aware context.

- Store conversations, facts, entities, preferences, and events as connected graph data.
- Extract entities and relationships from new interactions using configurable LLM adapters.
- Retrieve relevant memories through graph traversal, full-text search, and vector similarity.
- Support memory lifecycle controls: confidence scoring, deduplication, updates, expiration, and deletion.
- Provide a simple SDK and REST API for integrating memory into agent applications.
